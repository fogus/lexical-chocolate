# lexical-chocolate

Utilities for building lexical contours.

## Using

**deps.edn**

    me.fogus/lexical-chocolate {:mvn/version "0.0.4"}

**Lein**

    [me.fogus/lexical-chocolate "0.0.4"]

**Maven**

	<dependency>
	  <groupId>me.fogus</groupId>
	  <artifactId>lexical-chocolate</artifactId>
	  <version>0.0.4</version>
	</dependency>
